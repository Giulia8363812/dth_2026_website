# Orange Data Mining

## What could be useful Open Source Software for European Studies?
## ORANGE DATA MINING! 

![orange_logo4](./assets/images/orange_logo4.png)

**Orange Data Mining** is a visual Open Source Software package developed at the **University of Ljubljana** for data visualization, machine learning, data mining, and data analysis. Its birth dates back to 1997, thanks to the British researcher **Donald Michie** who conceived his dea of an open toolbox for machine learning. 

This software provides a sort of canva that allows the users to build data analysis workflows without the necessity of writing codes, but simply by dragging widgets for specific data operations and creating a tree structure of data and analysis on a graphical interface.

This project is actively updated and maintained by a large community of numerous contributors participating in its development through GitHub: the latest commit dates back to November 8th 2026, indicating ongoing development and maintenance activities, and this graph  shows the amounts of commits over the past 3 months:

![Graph](./assets/images/orange3_screenshot.png)


The *issues tracker* contains 102 open issues and 2,504 closed issues and these high numbers suggests that developers regularly review feedback and work to address bugs and user requests, supporting the software's reliability and sustainability.

It use the license **GNU General Public License**  (version 3.0), as it shows on the official website and the project is developed by the Bioinformatics Laboratory at the University of Ljubljana and supported through institutional backing and community donations.

I believe this program could be very useful in different kinds of Humanities as it allows students to analyze large amounts of data without requiring advanced programming skills. In a field where not all students have extensive familiarity with these kind of tools, its easy accessibility, makes it particularly suitable for beginners, by making research more accessible and efficient through its visual interface that keeps it very simple and intuitive to use
The official website also provides detailed tutorials on how to use the software and an extensive FAQ section that can be accessed. 






### A concrete research example: 
A concrete example I can provide is my thesis project in European Studies, in which I will analyze data related to gender equality in European institutions: through Orange Data Mining program, it would be possible for me to import a large dataset containing information on the composition of the various European Commissions and create visualizations showing the proportion of women and men in leadership positions, identifying trends over time. 

As this research project will require me to organize, compare, and analyse a large amount of data, this software would help make the process more streamlined and efficient, reducing the risk of confusion and errors.
