# Orange Data Mining

## What could be a useful Open Source Software for European Studies?
## ORANGE DATA MINING! 

![orange_logo4](./assets/images/orange_logo4.png)

**Orange Data Mining** is a visual Open Source Software package developed at the **University of Ljubljana** in 1997 by **Donald Michie** for data visualization, machine learning, data mining, and data analysis. 

It provides a canva that allows the users to build data analysis workflows without the necessity of writing codes, simply by dragging widgets for specific data operations and creating a tree structure of data and analysis on a graphical interface.

This project is actively updated and maintained by a large community of many  contributors participating in its development through GitHub: the latest commit dates back to November 8th 2026. This graph  shows the amounts of commits over the past 3 months:

![Graph](./assets/images/orange3_screenshot.png)


The *issues tracker* contains 102 open issues and 2,504 closed issues and these suggests that developers regularly review feedback and work to address bugs and user requests, supporting the software's reliability and sustainability.

It use the license **GNU General Public License**  (version 3.0), as it shows on the official website, and the project is developed by the Bioinformatics Laboratory at the University of Ljubljana and supported through institutional backing and community donations.

I believe this program could be very useful in different kinds of Humanities as it allows students to analyze large amounts of data without requiring advanced programming skills since is very simple and intuitive. In a field where not all students have extensive familiarity with these kind of tools, its easy accessibility, makes it particularly suitable for beginners.
The official website also provides detailed tutorials on how to use the software and an extensive FAQ section.






### A research example: 
A concrete example is my thesis project in European Studies, in which I will analyze data related to gender equality in European institutions: through Orange Data Mining program, it would be possible for me to import a large dataset containing information on the composition of the various European Commissions and create visualizations showing the proportion of women and men in leadership positions, identifying trends over time. This program would help make the process more streamlined and efficient, reducing the risk of confusion and errors.
